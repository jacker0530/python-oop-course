Python 類別 (Class) 與物件 (Object)

從「設計藍圖」到「實體創造」的物件導向程式設計入門

1 核心觀念：什麼是類別與物件？

📐 類別 (Class) ＝ 設計藍圖

類別就像是一張「魔法精靈設計圖」或「餅乾模具」。它定義了這個東西應該有哪些屬性（特徵）與方法（動作），但它本身還不是一個真實存在的實體。

✨ 物件 (Object) ＝ 實際成品

物件是根據類別這張藍圖「真正製造出來的實體」。你可以用同一張設計圖，創造出許多個擁有不同名字、不同屬性的獨立物件！

2 Python 程式碼結構解析 

# 1. 定義類別 (設計藍圖)
class MagicPet:
    # __init__ 是建構子，用來設定物件的初始「屬性」
    def __init__(self, name, element):
        self.name = name        # 屬性：名字
        self.element = element  # 屬性：魔法屬性

    # 定義「方法」(物件會做的動作)
    def cast_spell(self):
        print(f"✨ {self.name} 施展了強大的 {self.element} 魔法！")

# 2. 建立物件 (根據藍圖實體化)
pet1 = MagicPet("小綠", "森林")
pet2 = MagicPet("波波", "星光")

# 3. 呼叫物件的方法
pet1.cast_spell()  # 輸出：✨ 小綠 施展了強大的 森林 魔法！
pet2.cast_spell()  # 輸出：✨ 波波 施展了強大的 星光 魔法！
